# birthday-dad

爸爸生日快乐 🎂 —— 一份特别的生日祝福网页

## 预览

直接在浏览器中打开 `index.html` 即可预览。

## 功能

- 🎈 漂浮气球动画
- 🎊 五彩纸屑
- 🎂 互动蛋糕（点击蜡烛吹灭）
- 🎆 烟花效果（吹灭所有蜡烛后触发）
- 🎵 生日快乐歌（Web Audio API 演奏）
- 📱 响应式设计，支持手机浏览

## 部署

部署到 GitHub Pages：

```bash
bash scripts/deploy_github_pages.sh birthday-dad <github-username>
```

自动部署到 `https://<username>.github.io/birthday-dad/`
